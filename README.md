# Manual-Testing

This repository contains the documentation and test cases for the **Manual Testing** of an e-commerce website. The goal of this project is to ensure the application functions correctly and meets the user requirements.

## Sailor - Manual Testing Project

## Overview
This repository contains documentation and artifacts related to the manual testing of the Sailor.Clothing e-commerce website. It includes various testing documents such as the test plan, test scenarios, test cases, bug reports, and more.

## Project Components

1. **Test Plan**: The test plan outlines the overall testing strategy and objectives for the "Sailor.Clothing" project.

2. **Mind Map**: A visual representation of the project's testing scope, features, and dependencies to quickly understand the coverage.

3. **Test Scenarios**: Detailed descriptions of various test scenarios to be executed during the testing phase.

4. **Test Cases**: A collection of test cases that provide step-by-step instructions on how to execute specific tests.

5. **Test Summary Report**: A comprehensive report summarizing the testing process, including test results and observations.

6. **Bug Report**: Records of identified issues, defects, and anomalies found during testing, along with their status and resolution.

7. **Test Matrix**: A matrix that provides an overview of test coverage and the status of individual test cases.
